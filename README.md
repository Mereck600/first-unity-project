# Welcome to the source code for our Driving Simulator
## Built for Meta VR using Unity

This is a simple racing game with custom-built maps and driving mechanics.

This game was designed in Unity using the 6000.3.7f1 editor version. You may need to install this for the game to import correctly.

# Usage
Feel free to clone this game and import it into Unity. You will need to ensure you have Meta XR packages installed and an Android build system.
```
git clone https://github.com/Mereck600/first-unity-project.git
```
There are many online guides on how to build this game for your headset, so simply look online if you are confused.
